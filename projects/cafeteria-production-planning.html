Operations Research Optimization — Cafeteria Production Planning

A linear programming model to optimize production quantity and pricing under demand, resource, and operational constraints.

BUET Gurobi Excel Solver

Overview

This project applied operations research techniques to a real production-planning problem in a university cafeteria setting: deciding production quantities and pricing so as to make the best use of limited resources while meeting demand.

Approach

  • Formulated a linear programming model capturing demand, resource, and operational constraints.
  • Solved and validated the model using both Gurobi and Excel Solver.
